# 注音校准进度（更新至 2026-10-09）

## 判定口径

- “可靠整句”指网页或教材直接给出逐字拼音，程序按已核对的原句片段匹配，不使用单字首音推演。
- 简体、繁体和简繁混排正文统一归一后再匹配，显示仍保留原文字形。
- 未被可靠整句覆盖的文字仍会显示读音，但目前来自通假字规则、词组词典或单字读音，不能标记为“已完全校准”。
- 覆盖率按页面实际传给注音仓库的 `culture_passages/*.json` 每条 `original` 分别计算；只计成功匹配并锁定的汉字，同一字不重复计数。复算命令：`python tool/audit_classic_pinyin.py`。
- 旧表按较长的来源文本估算，没有考虑页面逐段调用；因此旧表多项偏高。下表是按现行程序匹配方式重新计算的有效覆盖率。
- 本文件是开发审计记录，不在应用界面展示数据来源说明。
- 2026-10-01 起，诗词词组覆盖按程序的整句优先锁定、简繁归一和标点边界复算；不把跨标点词组算作命中。此前各批次数字是历史记录，当前结果以覆盖率表为准。

### 版本差异核对

- 比对时仅归一标点与简繁字形；增删字、换字、句序不同的段落不套用来源读音。即使文字相同，遇到多音字仍结合句义和其他资料复核。
- 百度汉语《道德经·第二章》与应用的“故有无相生……恒也”“夫唯弗居，是以不去”两段不完全一致；第四章“吾不知谁之子，象帝之先”和第八章“居善地……动善时”也未通过逐字比对，均未导入。
- 《将进酒》的应用版本以“但愿长醉不复醒”为准；网页逐字拼音中该处误把“复”标成“愿”的读音，已核为 `fù`。其他异文仅在完全对应应用正文时录入。
- 《天工开物·治铁》“凡山林无煤之处，锻工先择坚硬条木烧成火墨……”与用户给出的注音页文字未逐字一致，整段保持待校准。

## 暂不采用

- 365 工具箱诗词注音：页面明确说明拼音由 `pinyin-pro` 实时生成，古诗古今异读、专名和多音字可能偏差。
- 注音图书馆：作为检索线索保留，但未找到足以证明其全文多音字经过人工校订的说明，暂不批量导入。
- 国学梦《千字文》“靡恃己长”的 `mí` 与古文之家 `mǐ` 不同；《临深履薄》的 `báo` 与汉典 `bó` 不同。这两处没有采用国学梦读音。
- 《心经》两个来源对个别字的读音和字形不一致；只录入应用现有原文里逐字核定的部分。应用没有收录的咒语等段落不计入 100% 摘录覆盖率。

## 仍需单独寻找或校定

- 尚缺本书专门逐篇注音来源的 4 部：周礼、孙膑兵法、棋经十三篇、抱朴子。跨书重复的短句可产生少量命中，不能据此认为这些书已完成逐篇校定；徐霞客游记目前仅找到《游黄山日记后》，墨子也仅有少量篇章对齐。
- 老子、易传、韩非子、文心雕龙等书的未覆盖段落仍需逐段寻找注音版本。
- 既有 4,140 条来源记录中，跨越应用段落的长句需先按原文和拼音逐字对齐后才能真正提高程序内覆盖率，不能把“来源中存在”直接计为应用已校准。
