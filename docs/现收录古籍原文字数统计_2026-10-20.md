## 统计口径

- 以 [`culture_items_v2.json`](../assets/data/culture_items_v2.json) 中 ID 以 `classic-` 开头、且指定 `passagesAsset` 的条目为范围；逐一读取 [`culture_passages/`](../assets/data/culture_passages/) 中对应 JSON 的 `original` 字段。
- “原文汉字数”统计 Unicode 中日韩统一表意文字、兼容表意文字及“〇”；不计标点、数字、拉丁字母、空白和缺字占位符。
- “原文字符数（去空白）”统计 `original` 中的全部非空白字符，包含标点、数字和缺字占位符，供不同计数习惯核对。
- 标题、小标题、目录摘要、译文、注释和拼音均不计入原文；目录 `content` 字段只是内容预览，不与分段原文重复累计。
- 《三字经》《弟子规》《千字文》虽在应用中归入“其他”分类，仍属于 `classic-` 原文资源，计入本表。此前移除的《抱朴子》《山海经》《孙膑兵法》，及本次移除的原榜单第 1—14 号文献均不计入。
