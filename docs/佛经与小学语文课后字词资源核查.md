# 佛经与小学语文课后字词资源核查

核查日期：2026-09-28。目标：寻找可供本项目使用的两类资源：①汉文佛经正文与目录；②中国小学统编版语文一至六年级、上下册的课后生字和词语。本文是来源与权利核查记录，不是已获准导入清单。执行准入时遵循[素材筛选、终选与废案规则](素材筛选、终选与废案规则.md)。

## 结论

| 需求 | 已找到的可靠来源 | 当前结论 |
| --- | --- | --- |
| 汉文佛经 | CBETA 官方 XML、纯文本、目录 API、电子书 | 内容和结构满足检索、校对研究需求；其数据库限制非营利使用，**不能直接作为本项目可自由打包分发的资源**。若需正式集成，须核实本项目用途并取得适用授权。 |
| 小学一至六年级课后字词 | 国家中小学智慧教育平台的统编教材、人教社教材说明；第三方逐课整理可作比对线索 | 官方教材可作为核对基准；未找到**同时证明为 2026 年新版十二册、逐课完整、可在应用内再分发**的结构化数据集。不得将旧版或“重点词”数据称为“全部课后字词”。 |

“课后生字、词”按**小学语文**理解。数学、英语等学科没有同一种“会认字／会写字／词语表”结构；若产品要收录其他学科，应另立数据范围。

## 1. 佛经资源

| 资源 | 格式与用途 | 权利与完整度判断 |
| --- | --- | --- |
| [CBETA 官方 XML P5](https://github.com/cbeta-org/xml-p5) | TEI XML，保留经名、作译者、卷、行号及校勘等结构，最适合建立结构化目录和正文。 | 官方对外版本；仍受 [CBETA 使用说明](https://archive2.cbeta.org/copyright.php)约束，不能因 GitHub 仓库公开就推定可商用或自由再分发。 |
| [CBETA Normal Text](https://github.com/DILA-edu/cbeta-normal-text) | 一卷一文件，依原书换行，行首带定位信息，适合文本检索原型。 | 与 XML 同源，不是第二套独立授权佛经库；纯文本较难保留完整校勘结构。 |
| [CBETA 目录 API](https://cbdata.dila.edu.tw/stable/static_pages/catalog) | 可取得部类、经号、经名、作译者、卷次等元数据，并识别仅指向异本、未收录全文的目录节点。 | 适合先做目录与范围盘点；API 可访问不等于允许应用离线缓存和再分发正文。 |
| [CBETA 官方电子书](https://cbeta.org/ebooks) | 单部或批量 EPUB、PDF、DOCX、ODT，适合人工核对阅读效果。 | 适于阅读与校对，不宜作为首选结构化导入源；仍遵守 CBETA 使用说明。 |

CBETA 收录的是**佛教文献集成**，包含经、律、论、史传等。若界面标题为“佛经”，须依据经录部类或经号筛选，不能把整个库都标成佛经。[CBETA 部类目录说明](https://www.cbeta-org-tw.cbeta.org/data/cbeta/cbeta_toc.htm)列出了阿含、般若、法华、华严、涅槃、律、论等部类。

[CBETA 官方版权声明](https://archive2.cbeta.org/copyright.php)规定数据库限个人或团体非营利用途；营利用途须事先取得基金会和底本权利人同意。再传播或再加工发行需保留使用说明与版本信息。部分近现代文献明确不在其通用 CC 授权范围内。**本轮准入状态：废案（针对直接打包发行 CBETA 正文的方案）；官方来源保留为研究与授权联系入口。**

## 2. 小学语文课后生字、词

### 官方核对基准

1. [国家中小学智慧教育平台](https://basic.smartedu.cn/)提供数字教材。教育部说明平台有出版社提供的电子版教材，可供师生使用；这不等于授权其他应用复制、打包和再分发。[教育部平台说明](https://www.moe.gov.cn/fbh/live/2022/54324/sfcl/202203/t20220329_611596.html)。
2. [教育部 2024 年教学用书目录](https://www.moe.gov.cn/srcsite/A26/s8001/202408/W020240805496325238752.pdf)列出统编语文教材范围。核对数据时，应逐册记录书名、年级、册次、修订版次和实际启用年份。
3. [人教社教材说明](https://www.pep.com.cn/products/jc/jks/201608/t20160823_1369629.shtml)指出低年级教材附有识字表、写字表；中高年级还须核对各册的词语表及每课课后栏目。不能把“会认”“会写”“词语”合并为一种字段。
4. [人教社修订说明](https://www.pep.com.cn/bks/xxyw/jzjd/202505/W020250531415592673618.pdf)明确修订版一年级上册识字量由 300 个调整为 280 个。因此旧版列表即使看似完整，也不能直接冒充新版。

[教育部的新教材启用安排](https://www.moe.gov.cn/jyb_xwfb/s5147/202408/t20240828_1147579.html)是：2024 年先在小学一年级使用，2025 年扩大至一至三年级，2026 年覆盖义务教育所有年级。整理“全部十二册”时须逐册确认对应的是同一轮修订版，不能混用旧版上册和新版下册。官方教材页面标注版权所有、未经许可不得复制或使用；例如[平台上的六年级上册 PDF](https://r2-ndr.ykt.cbern.com.cn/edu_product/esp/assets_document/2e3dc199-9c42-486b-bbee-7731bd0ee227.pkg/pdf.pdf)。**本轮准入状态：废案（针对未经授权批量抽取并打包发行教材数据的方案）；官方教材保留为核对基准。**

### 第三方整理的核查结果

| 来源 | 查到的内容 | 结论 |
| --- | --- | --- |
| [拉帮学派课后生字与词语表](https://sharedoc.shengshihongbo.com/toolbox/kehou-shengzi) | 页面提供一至六年级上下册入口，按课列“会认字”“会写字”和词语；一年级上册页显示约 300 个会认字。 | 与修订版一年级上册 280 个识字量不一致，版本至少需要重新核对；未见准许本应用批量再分发的授权。**废案：直接导入。** |
| [hanzi-park 数据报告](https://github.com/cjp1016/hanzi-park/blob/main/PEP-DATA-REPORT.md) | 自称覆盖十二册，但报告列出的是 120 个重点词，平均每年级 20 个。 | “十二册覆盖”不代表全部课后词；仓库 MIT 也不能代替教材内容授权。**废案：作为完整词库导入。** |
| [getword 参考词库](https://github.com/XUJiahua/getword) | 声明覆盖一至六年级上下册常见词语，同时说明与教材实际单元字词表不一定一一对应。 | 可作一般练习词参考，不能充当逐课完整教材数据。**废案：作为完整课后字词导入。** |
| [一年级 2024 版互动学习项目](https://github.com/jackli01030/shiyi-grade-one-yuwen) | 仅一年级上下册，含会认字、会写字和少量关键词语。 | 有版本参考价值，但未覆盖一至六年级全部十二册，关键词也非完整词语表。**废案：作为完整十二册数据导入。** |

### 若取得授权，所需数据结构与验收

建议按 `版本 → 年级 → 册次 → 单元 → 课次` 存储，逐课分设 `会认字`、`会写字`、`课后词语`，并保留册末表的原始顺序、页码和来源版本。不同册次未必都有册末词语表；空值应表示“本册无此栏目”或“尚未核对”，不能自动补造。

验收时逐册比对官方教材目录、每课栏目和册末字词表，统计课次覆盖率、字词数量、重复项、异体字与多音字标注；记录来源、修订年份、核对日期及许可文本。权利确认前，所有第三方数据只作来源线索，不进入应用资产或发布包。
