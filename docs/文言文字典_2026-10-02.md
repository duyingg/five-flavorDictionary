# 文言文字典（2026-10-02）

学习页新增“文言文字典”。输入单字或词语后，先显示现有单字词库的释义，再从 30 部本机文献中查找完全相同的原文字串，展示出处、原文片段和该段已有的译文，并可进入整部原文。

检索数据由 `tool/build_classical_lookup_index.py` 从现有 `culture_items_v2.json` 与 30 个 `culture_passages/*.json` 生成，覆盖 65,242 段。索引位于 `assets/data/classical_lookup_index.json.gz`，不含新增网络释义；修改文献原文或译文后，应运行 `python tool/build_classical_lookup_index.py` 重建索引。

查询按字形完全匹配。译文是整段解释，不自动断定查询词在该句中的唯一义项；单字词库释义也需结合原文判断。每部文献最多展示 3 条用例，最多 90 条结果，以避免常见虚词产生过长的列表。

检查：`flutter analyze` 对新增页面、学习页与路由无问题；`flutter test --no-pub test/widget/classical_dictionary_page_test.dart` 通过，验证“无为”可同时显示释义和典籍用例。
