# 小学语文写字表数据说明

## 当前实装范围

- 名称：人民教育出版社《义务教育教科书·语文》（统编版）写字表。
- 教材范围：一至六年级、上下册，共十二册。
- 审定年份：一年级 2016 年、二年级 2017 年、三年级 2018 年、四至六年级 2019 年。
- 条目总数：2500 条；跨册去重后 2484 字。
- 页面结构：年级 → 上下册 → 该册写字表；保持来源顺序。

这份资源是“会写字/写字表”，不是全部“会认字/识字表”，也不是 2026 年新修订版。上游没有逐课字段，因此本项目不虚构单元和课次。
